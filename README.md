# STOCKWISE AI

A school AI capstone prototype: a premium, dark-themed stock market learning dashboard built with plain **HTML, CSS and vanilla JavaScript**. No frameworks, no build step, no server.

> **DEMO DATA: Values are illustrative and are not live market prices.**
> All companies are fictional. Nothing here is financial advice, and no real money is ever used.

## Features

- **Dashboard**: welcome section, market overview cards, company search, watchlist, historical chart, recently viewed companies
- **Stock analysis**: company information, sample prices, percentage changes, interactive chart, educational AI trend analysis
- **AI learning assistant**: chat with pre-written answers about stocks, IPOs, shares, dividends, exchanges and financial terms
- **Company comparison**: compare two or three sample companies with charts and a metrics table
- **Virtual trading simulator**: ₹1,00,000 fictional balance, buy and sell, portfolio overview, transaction history
- **LocalStorage**: your watchlist, recent companies, chat, portfolio and transactions are saved in your own browser

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and all five views |
| `style.css` | Design and responsive layout |
| `script.js` | Sample data, charts, search, chatbot, simulator |
| `README.md` | This guide |

Charts use [Chart.js](https://www.chartjs.org/) loaded from a CDN, so an internet connection is needed for charts to appear.

## Run it on your computer

Double-click `index.html`. It opens in your browser.

## Publish with GitHub Pages

1. Sign in at github.com and click **New repository**.
2. Name it `stockwise-ai`, choose **Public**, and click **Create repository**.
3. Click **uploading an existing file**, drag in `index.html`, `style.css`, `script.js` and `README.md` (the files themselves, not a folder), then click **Commit changes**.
4. Open **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then click **Save**.
5. Wait 1 to 2 minutes and refresh. Your site appears at `https://YOUR-USERNAME.github.io/stockwise-ai/`.

## How the sample data works

Prices are generated by a small seeded formula in `script.js`, so they are the same every time. They are not copied from any real market. "Simulate next day" adds one more made-up day to every chart.

## Limitations

This is an educational prototype. The AI assistant uses pre-written answers, and the trend analysis is a simple rule-based example, not a prediction.
